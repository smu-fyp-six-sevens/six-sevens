How the AI is tested

The real code runs end to end: endpoints, workers, the document pipeline with real text extraction and OCR, the content guard's scan of each file, and the detection graph with its real tools. Only Claude's replies are scripted.

  • What it proves: injected instructions are stopped at upload before any model reads them; the specialists can't dismiss or lower a guard finding even when scripted to try; page forgeries are flagged; the trace keeps what a cancelled run did.
  • What it doesn't: whether Claude picks the right tools and ratings on the real documents. That's the manual live run at the end of each sprint.
  • Real data in the browser: the Accuracy tab and the Audit Trail render what the backend produced (shared fixtures), and the dashboard's risks are the backend's scoring. A backend test fails if either drifts.
  • No credits spent: the tests block any real Claude request, even with a real API key in .env.

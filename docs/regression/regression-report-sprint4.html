How the AI is tested

The real pipelines run end to end: the case analysis endpoint, case-worker and scoring; the document pipeline's extraction and its retry; and the detection graph with its real tools. Only Claude's replies are scripted.

  • What it proves: scoring runs only after the cross-document check and includes its findings; one run at a time; an invalid reply is retried once, then fails only that document; the checks flag each test case's mismatch.
  • What it doesn't: whether Claude picks the right tools, hypotheses and ratings on the real documents. That's the manual live run at the end of each sprint.
  • Real figures: the risk score reproduces the live run exactly: Critical 89/100, 60 points from 7 findings, 87 without the cross-document finding. The browser suite renders those same results (shared fixture).
  • No credits spent: the tests block any real Claude request, even with a real API key in .env.

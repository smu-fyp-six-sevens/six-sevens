How the AI is tested

The real LangGraph pipeline runs end to end: queue, text extraction, rule classifier, classify agent, extraction, and saving the results. Only Claude's replies are scripted, and the extraction replies reuse real results saved from Supabase.

  • What it proves: given what the AI answers, the pipeline records the right type, confidence, routing, status changes and fields.
  • What it doesn't: whether Claude still gives the right answers for the real documents. That's the manual live run at the end of each sprint.
  • No credits spent: the tests block any real Claude request, even with a real API key in .env.
